# CSS Exercise

### Part 1
- Create a folder called css_exercise and in it an index.html
- Open the folder in VS Code and copy paste the content of index.html
(from Slack)
- Start the live server and open the page in Firefox
- Add inline CSS to change the color of the background of the body element
to beige
- Create a new file in the folder called styles.css, link it in the HTML file
- Remove the inline CSS you added just before, and write that rule in
styles.css instead
- From now on, we will work only with external CSS, no more inline styling

### Part 2
- Set all the size of paragraph texts to 16px.
- Change the color of the text of the ordered list to orange
- Import a font (either through a local file or Google Fonts) and change the
font in the h1 header (don’t forget to add fallbacks!)
- Make all emphasised text bold
- Remove the underlining of the links, in all 4 states (see slide 15). You can
use the text-decoration-line property.
- Make the corners of the image rounded (we didn’t cover this property in the
lecture, search online for how to do it)

### Part 3
- Add a class to the h2 and h3 headers called subheaders, and use it to
change their color to blue
- Add an id to the first paragraph called intro-text, and use it to make its
font size a bit bigger than the rest of the text
- Add an id to the last div, the one encompassing the application process, call
it whatever you want, add a border and change its width, height, margin
and padding. Experiment with different values and see the results
